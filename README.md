# project_saxs-xlms-md_rad

This repository contains the necessary code to conduct the analyses and reproduce the figures in *Bresciani, V. et al., JCIM, 2025* ([doi.org/10.1021/acs.jcim.5c01639](https://doi.org/10.1021/acs.jcim.5c01639)). Strided trajectories are provided here to reduce file size, see below for full trajectories to reproduce the full analyses. 

Input files to perform the simulations, along with output data (including trajectories) that we generated in our work are freely available in Zenodo with accession code [10.5281/zenodo.17205343](https://zenodo.org/records/17205343).
